
# 🛍️ RetailPulse Analytics Dashboard | Power BI

This repository contains an **interactive Power BI dashboard** for analyzing retail sales, business performance, and customer trends.

## 📝 Report Tabs

### 1️⃣ RetailPulse Analytics Dashboard
- 📊 Key Performance Indicators (KPIs)
- 🆕 New and Returning Customers
- 🔝 Top N and Bottom N Analysis
- 💰 Sales and Profit Insights

### 2️⃣ Cohort Analysis
- 📈 Cohort diagram to analyze customer behavior and trends over time.

## 🎯 Project Objective
To analyze retail performance, identify trends, and support data-driven business decisions.

## 🛠️ Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
